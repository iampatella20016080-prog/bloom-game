# 綻放 BLOOM：產後 180 天

性別研究課程小組作業。一款大約 8 分鐘的手機網頁遊戲：你是剛生完的媽媽，手機裡的身材管理 App「BLOOM」要你在 180 天內「找回自己」。

核心問題：**為什麼產後女性必須在六個月內「恢復身材」？這個期限是誰訂的？誰從中獲利？**

文本：上野千鶴子《父權體制與資本主義》、鄭斐文〈肥胖科學、醫療化與性別身體政治〉、高夫曼《污名》。

## 檔案

| 檔案 | 內容 |
|---|---|
| `cards.js` | 所有劇情、卡片、Boss、理論卡文字（**改文字只要改這個**） |
| `config.js` | 全班數據的 Google 表單設定 |
| `game.js` | 遊戲引擎 |
| `index.html`、`style.css` | 畫面與樣式 |

不需要安裝或打包，是靜態網頁。

## 本機試玩

```bash
python3 -m http.server 8765
```

然後打開 http://localhost:8765 。

## 網址參數

| 參數 | 用途 |
|---|---|
| `?menu` | 報告者模式：跳章、理論卡圖鑑、全班結果、QR code（不會送出全班數據） |
| `?results` | 直接打開全班結果 |
| `?deck` | 理論卡圖鑑 |
| `?ch=2` | 從第 2 章開始 |
| `?boss=2` | 直接玩第 2 章的 Boss |
| `?skip` | 跳過開場 |
| `?nosend` | 玩完不送出全班數據 |
| `?full` | 完整版：所有卡片和每一張理論卡（預設是給同學的 8 分鐘精簡版） |
| `?timer` | 右上角顯示碼表，彩排計時用 |
| `?finale=hidden` | 直接看某一種結局（`hidden`／`reach`／`crash`／`fail`，用示範數字，不送全班數據） |

正式網址：https://bloom-game-eta.vercel.app/
